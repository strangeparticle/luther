# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities — that would disclose the
problem before a fix exists.

Report it privately through GitHub: on this repository's **Security** tab, click
**"Report a vulnerability."** That opens a private advisory visible only to the maintainer.
If you can't use that, email **admin@strangeparticle.com**.

You'll get an acknowledgement, and we'll coordinate a fix and its disclosure with you.

## Supported versions

luther is pre-1.0; fixes land on the latest published release.
